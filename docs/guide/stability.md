# Linear stability of a system

Every quantity levisim calculates for a `MultiTrap` - the optical and position spectra by all seven
methods, and the steady-state covariance of {mod}`levisim.multiphysics.covariance` - belongs to the
stationary state of the linearised Langevin equations $\dot{\hat{\mathbf c}} = \mathbf A
\hat{\mathbf c} + \hat{\mathbf c}_\text{in}$. That state exists only if every eigenvalue $\lambda$ of
the drift matrix $\mathbf A$ has a negative real part. If one does not, the mode it belongs to grows
as $e^{\mathrm{Re}\,\lambda\, t}$ until the linearisation breaks down, while the spectra are still
finite numbers that describe nothing physical. This page shows how to check, and which of the ready-made systems are unstable.

## The stability report

Each `MultiTrap` diagonalises its drift matrix once, when it is built, and reports:

| Attribute | Meaning |
|---|---|
| `drift_eigenvalues` | the eigenvalues $\lambda$ of $\mathbf A$, largest real part first [s⁻¹]; $\lvert\mathrm{Im}\,\lambda\rvert$ is a normal-mode angular frequency and $-\mathrm{Re}\,\lambda$ its amplitude damping rate |
| `max_growth_rate` | $\max \mathrm{Re}\,\lambda$ [s⁻¹]: minus the damping of the least-damped mode if stable, the growth rate of the fastest-growing mode if not |
| `is_stable` | whether every $\mathrm{Re}\,\lambda$ is below `stability_tolerance` ($10^{-8}$ of the largest $\lvert A_{ij}\rvert$, which absorbs round-off in the decay rates of dark modes) |
| `least_stable_mode` | $(\Omega, \mathrm{Re}\,\lambda)$ of the eigenvalue with the largest real part, $\Omega = \lvert\mathrm{Im}\,\lambda\rvert$ in levisim's angular units (divide by `kHz`) |
| `unstable_modes` | $(\Omega, \mathrm{Re}\,\lambda)$ of every growing mode, each conjugate pair once; empty if stable |

`mtrap.info` prints the verdict, the largest $\mathrm{Re}\,\lambda$ and every growing mode, and
building an unstable system logs a WARNING from the same numbers:

```python
from levisim.multiphysics.multitrap import MultiTrap
from levisim.multiphysics.utils.shelf import DEFAULT_cavity_kwargs, DEFAULT_gas_kwargs
from levisim.core.units import kHz

mtrap = MultiTrap(num_traps=2, Cartesian_axes_per_trap=2,
                  gas_kwargs=DEFAULT_gas_kwargs, cavity_kwargs=DEFAULT_cavity_kwargs)
mtrap.is_stable                                           # False
[(Ω / kHz, rate) for Ω, rate in mtrap.unstable_modes]    # [(134.92..., 2677.5...)]
```

`steady_state_covariance` raises for an unstable system. A parameter sweep should record
`max_growth_rate` alongside each spectrum, as the demo notebook `06_parameter_sweeps` does.

## Which ready-made systems are stable

Generated by `docs/guide/scripts/stability_table.py` for every toy preset of
{mod}`levisim.multiphysics.utils.shelf` (in the shapes the shelf and the tests build them) and for
the physical defaults (built-in tweezers, with phases $\phi_n$ = 0°, 90°, 20°), each with the
shelf's gas and cavity keyword arguments and with the constructor defaults. The number in brackets
counts the growing normal modes. The phase sign convention does not enter the drift matrix, so the
shelf's `tweezer_phase_sign_convention = -1` systems behave as the $+1$ ones listed.

```{include} tables/stability_table.md
```

Three kinds of instability appear. With two or more particles whose motions are close in frequency
and whose tweezer phases differ (the physical 2×2 and 3×2 defaults, `PHASE_DEPENDENT` with three or
four particles, `OFF_NODE_toy_params_pairs` with two or more), the cavity-mediated coupling has a
non-reciprocal part $\propto \sin(\phi_2 - \phi_1)$ that anti-damps one collective mode near the
mechanical frequencies. With three axes per particle off the node (every `OFF_NODE` preset in
$N\times 3$), the strong $z$ coupling `toy_gz` = 170 kHz pulls the slow $z$ motion
($\Omega_z = \Omega_x/10 \approx$ 30 kHz) through zero frequency: the optical spring exceeds the
trap stiffness and the eigenvalue becomes real and positive ($\mathrm{Im}\,\lambda = 0$), a static
instability rather than a growing oscillation. And the constructor-default cavity, closer to
resonance ($\Delta/2\pi$ = -180 kHz instead of -450 kHz), couples the motions more strongly, so that
systems which are stable with the shelf's cavity (the physical 2×1, `PHASE_DEPENDENT` 2×2, and
several `OFF_NODE` spacings) become unstable with it.

## The phase window of the default 2×2 system

Two particles from the physical defaults, each moving in $x$ and $y$, with the second tweezer's phase
$\phi_2$ swept and $\phi_1 = 0$. The window repeats every 180°: adding 180° to $\phi_2$ flips the sign
of the couplings $G_{j_2} \propto e^{i\phi_2}$ of the second particle, which is undone by relabelling
its operators $\hat b_{j_2} \to -\hat b_{j_2}$, a similarity transformation of $\mathbf A$ that leaves
its eigenvalues unchanged.


The README's quickstart therefore sets $\phi_2 = 30^\circ$ rather than the built-in 90°.

# Showcase: three papers, and stability

These pages hold the interactive versions of the figures in the README: one example from each of my
three papers whose calculations levisim was written for or used in, and the eigenvalue stability
analysis that sits behind every system it models. Every figure is computed when the documentation is
built, by the script named on its page (in `docs/guide/scripts/showcase/`), so the numbers on the
site are those of the code at that commit. Hover for values, click legend entries to hide or show
curves, and drag to zoom; a double click resets the axes.

```{toctree}

prr5_mode_orientations
prr6_directional_force
prr8_mode_comb
stability_tweezer_phase
```

The schematics are renders of my Blender scenes for the thesis, labelled as in its figures.
